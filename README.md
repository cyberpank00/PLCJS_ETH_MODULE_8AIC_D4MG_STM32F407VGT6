<p align="center"><strong>Плата модуля 8AIC, HW1.0</strong></p>

Прошивка Ethernet-модуля PLCJS с 8 аналоговыми токовыми входами (4–20 mA /
0–20 mA) на базе `STM32F407VGT6`.

Модуль измеряет 8 каналов тока через два изолированных 24-битных АЦП
`ADS1220` (по 4 несимметричных входа на каждом через встроенный
мультиплексор), публикует показания по `Modbus TCP`, хранит настройки во
внутренней Flash, а калибровку — в отдельном одноразово записываемом
(write-once) секторе Flash, управляет главным индикатором `STAT_LED` и
восемью канальными светодиодами, поддерживает factory reset и программный
переход в Ethernet bootloader для OTA-обновления.

MAC-адрес уникален для каждого изделия: он детерминированно выводится из
96-битного уникального ID кристалла `STM32` (не хранится и не требует
провизионинга), поэтому в приложении и в bootloader он совпадает автоматически.

Базовая архитектура (сеть, Modbus TCP сервер, настройки, LED, bootloader/OTA,
драйвер ADS1220, write-once калибровка) унаследована от варианта `4RTD`
HW2.1.

## Аппаратная платформа

| Узел | Описание |
|---|---|
| MCU | `STM32F407VGT6`, Cortex-M4F |
| Ethernet | `KSZ8863` switch/PHY, RMII |
| АЦП | 2× `ADS1220` (24 бит, Δ-Σ), гальванически изолированы (CA-IS3xxx), DRDY разведён |
| Опора | `REF5020` 2.048 V (0.05 %, 3 ppm/°C) → REFP0/REFN0 |
| Вход канала | предохранитель 0.1 A → шунт **91 Ω 1206** (в прошивке номинал 89.9 Ω, калибруется) → 1 kΩ + 100 nF → AINx; клампы BAV99, TVS SMAJ24CA |
| Температура MCU | внутренний датчик (`ADC1_IN16`) |
| Factory reset | кнопка `FACT_RES`, active-low (также подтверждает аварийный сброс калибровки) |
| Индикация | `STAT_LED` + 8 канальных светодиодов |
| Watchdog | `IWDG` |

### Распиновка

| Сигнал | Пин | Сигнал | Пин |
|---|---|---|---|
| SPI1 SCLK | PA5 | SPI1 MISO | PA6 |
| SPI1 MOSI | PB5 | | |
| ADC0_CS | PA9 | ADC1_CS | PD8 |
| ADC0_DRDY | PD10 | ADC1_DRDY | PD9 |
| AI0_STAT | PB15 | AI1_STAT | PB14 |
| AI2_STAT | PB10 | AI3_STAT | PE15 |
| AI4_STAT | PE14 | AI5_STAT | PE13 |
| AI6_STAT | PE12 | AI7_STAT | PE11 |
| STAT_LED | PE9 | FACT_RES | PE10 |
| ETHRST | PD11 | ETHINT | PB1 |

ADC0 обслуживает AI0…AI3 (AIN0…AIN3), ADC1 — AI4…AI7. SPI: master, 8-бит,
MSB first, mode 1 (CPOL=0, CPHA=1), ~2.6 МГц.

### Конфигурация ADS1220

| Регистр | Значение | Поля |
|---|---|---|
| 0 | `0x81 \| mux<<4` | MUX AINx/AVSS, gain 1, **PGA bypass** |
| 1 | `DR<<5` | 20/90/330 SPS, normal, **single-shot** |
| 2 | `0x50` / `0x40` | внешняя опора REFP0/REFN0, FIR 50+60 Гц (только на 20 SPS), IDAC off |
| 3 | `0x00` | — |

Опрос: для каждого из 4 входов мультиплексора — WREG MUX → START на **обоих**
АЦП → ожидание DRDY → RDATA. Полный скан 8 каналов = 4 преобразования
(≈ 210 мс на 20 SPS, ≈ 50 мс на 90 SPS, ≈ 16 мс на 330 SPS).

```
I_raw = code / 2^23 × V_REF / R_shunt        (20 mA ≈ 1.8 V ≈ 88 % шкалы)
I     = gain × I_raw + offset                 (калибровка канала)
```

### Канальные светодиоды

- **горит постоянно** — канал активирован, ток в норме;
- **не горит** — канал деактивирован;
- **быстро мигает (5 Гц)** — ошибка: обрыв (< 3.6 mA на live-zero шкале),
  перегрузка (> 21 mA или насыщение АЦП), АЦП не отвечает.

## Шкала канала и детекция ошибок

Шкала каждого канала задаётся двумя порогами в мкА — нижним (`8 + ch`,
по умолчанию 4000) и верхним (`16 + ch`, по умолчанию 20000). Показание
int16 (`0 + ch`) автоматически масштабируется: нижний порог → `0`, верхний →
`32767`, ниже нижнего — отрицательные значения. Для шкалы 0–20 mA достаточно
записать нижний порог `0`.

| Условие | Ошибка |
|---|---|
| нижний порог ≥ 3600 мкА **и** `I < 3.6 mA` | обрыв (код 1) |
| `I > 21 mA` или насыщение АЦП | перегрузка (код 2) |
| нет DRDY / не читается конфигурация | АЦП не отвечает (код 3) |

Пороги ошибок зашиты константами `AIC_OPEN_MA` / `AIC_OVER_MA` в
`aic_module.h`. Максимальный измеримый ток при шунте 89.9 Ω — ≈ 22.8 mA.

## Калибровка

Каждый канал калибруется по 2-точечной (или многоточечной) линейной модели
`I = gain × I_raw + offset` от прецизионного источника тока по Modbus TCP
инструментом в `tools/` (Node.js или Python). Калибровка убирает допуск
шунта, ошибку опоры и деление 1 kΩ / входное сопротивление АЦП.

### Точность 0.2 % в −20…+70 °C

Бюджет после калибровки при ~25 °C (ΔT = 45 °C): шунт 25 ppm/°C — 0.113 %,
саморазогрев шунта 1206 (+9 °C при 20 mA) — 0.023 %, REF5020 3 ppm/°C —
0.014 %, АЦП/делитель — ~0.01 %. Сумма ≈ 0.16 % (RSS ≈ 0.12 %). Шунт
**тонкоплёночный, 0.1 %, ≤ 25 ppm/°C, 1206** — обязательное условие.

### Одноразовая запись (write-once)

Калибровка хранится в отдельном секторе Flash (sector 11), который прошивка
**никогда не стирает** в обычной работе — она переживает factory reset. Каждый
из 8 слотов (по каналу) можно зафиксировать (commit) **ровно один раз**:

1. записать `gain`/`offset` в регистры `540 + ch×4` — живой предпросмотр;
2. записать `0xCA00 | ch` в регистр `131` (**CAL COMMIT**) — слот
   программируется во Flash и блокируется;
3. статус блокировок — input-регистр `127` (бит = канал).

Попытка записи в `540+` или повторного commit для заблокированного слота
возвращает `ILLEGAL DATA VALUE`.

### Аварийный сброс калибровки (двухфакторный)

1. записать `0xC1A5` в регистр `132` (**CAL ERASE ARM**) — окно 30 с;
2. в течение окна удержать кнопку `FACT_RES` ~3 с.

Сектор калибровки стирается (все слоты → `gain=1.0, offset=0.0`), модуль
перезагружается. Одного действия недостаточно.

## Карта регистров Modbus

Числа с плавающей точкой — IEEE-754 float32 в двух регистрах, **старшее слово
первым**. Многоканальные величины сгруппированы **по величине**: 8 регистров
(или 8 пар) подряд — каналы 0..7.

### Компактный блок — Holding Registers (FC03/06/16), 0..47

| Рег | Описание |
|---|---|
| 0..7 | **показание, int16 (RO)**: `0..32767` ↔ `[нижний порог … верхний порог]` канала, ниже нижнего — отрицательное (кламп ±32767); канал выключен — `0`; ошибка — `−32768` (`0x8000`) |
| 8..15 | нижний порог шкалы, мкА (по умолч. `4000`; 0..25000, меньше верхнего) |
| 16..23 | верхний порог шкалы, мкА (по умолч. `20000`; до 25000, больше нижнего) |
| 24..31 | enabled (0/1, по умолч. `1`) |
| 32..39 | сглаживание EMA (0 = выкл, 1 = 1/4, 2 = 1/8, 3 = 1/16) |
| 40..47 | резерв (0) |

Пороги проверяются друг относительно друга: при сдвиге всей шкалы вверх
сначала записывайте верхний порог. Одним запросом `FC03 0..7` читаются
показания всех каналов.

### Показания — Input Registers (FC04), 300..355

| Рег | Тип | Описание |
|---|---|---|
| 300..315 | float32 ×8 | ток, mA (калиброванный, сглаженный); NaN при ошибке/выкл |
| 316..331 | float32 ×8 | «сырой» ток, mA (вход калибровки) |
| 332..339 | u16 ×8 | флаги: bit0 enabled, bit1 valid, bit2 fault; bits15..8 код ошибки (1 обрыв, 2 перегрузка, 3 АЦП) |
| 340..355 | int32 ×8 | 24-битный код АЦП (старшее слово первым) |

Глобальные: `120` fw major, `121` fw minor, `122/123` uptime (с), `125`
module id (`0x08AC`), `126` температура MCU (signed 0.1 °C), `127` маска
блокировки калибровки (бит = канал).

### Общие настройки — Holding Registers

| Рег | Описание |
|---|---|
| 100 | период опроса, мс (50..5000; фактический скан ≥ 4 преобразований) |
| 101 | режим LED (0/1/2) |
| 102 | Modbus slave id | 103 | Modbus TCP порт |
| 104..107 | static IP | 108..111 | netmask | 112..115 | gateway |
| 116 | net mode: `0` static / `1` DHCP / `2` link-local (default `2`) |
| 117 | SAVE (`0xA5A5`) | 118 | REBOOT (`0xB00B`) / BOOTLOADER (`0xB007`) / сброс KSZ8863 (`0x8863`) |
| 119 | FACTORY RESET (`0xDEAD`) | 130 | температура MCU (RO) |
| 131 | CAL COMMIT (`0xCA00 \| ch`) | 132 | CAL ERASE ARM (`0xC1A5`) |
| 133 | **скорость АЦП**: `0` = 20 SPS + FIR 50/60 Гц (по умолч.), `1` = 90 SPS, `2` = 330 SPS |

Коэффициенты калибровки (float32), база `540 + ch×4` (**write-once**):
`+0..1` gain, `+2..3` offset (mA). Номиналы: `620..621` R_shunt Ω (89.9),
`622..623` V_REF V (2.048).

## Программное сглаживание

Поканальный EMA на калиброванном токе (регистры `32..39`): `I = I + α·(I_изм − I)`,
α = 1/4, 1/8, 1/16. Время установления: `t(63 %) ≈ T_скан/α`,
`t(95 %) ≈ 3·T_скан/α`. Фильтр перезапускается после ошибки и любого
изменения конфигурации канала. «Сырой» ток и код АЦП не фильтруются.

## Flash layout

| Область | Адрес | Размер | Назначение |
|---|---:|---:|---|
| Bootloader | `0x08000000` | 128 KB | sectors 0-4 |
| Metadata | `0x08020000` | 128 KB | sector 5 |
| Application | `0x08040000` | 256 KB | sectors 6-7 (эта прошивка) |
| Staging | `0x08080000` | 256 KB | sectors 8-9 |
| Settings | `0x080C0000` | 128 KB | sector 10 |
| Calibration | `0x080E0000` | 128 KB | sector 11 (write-once) |

`SETTINGS_MAGIC = 0x08AC4A57`, `SETTINGS_VERSION = 2`. Калибровка: 8
CRC-защищённых слотов, magic `0xCA11B08A`.

## Сборка

```powershell
cmake --preset Debug
cmake --build --preset Debug
```

Идентичность — `Application/fw_header/fw_header.h`: `FW_PRODUCT_ID=0x504C0804`,
`FW_HW_REVISION=0x0101`, `FW_VERSION_VALUE=0x0105`. Результаты в
`build/Debug/`; `.bin` — OTA-образ с `fw_header_t` по смещению `0x200`.

## Прошивка

```powershell
STM32_Programmer_CLI -c port=SWD -w build/Debug/PLCJS_ETH_MODULE_8AIC_D4MG_STM32F407VGT6.elf -v -rst
```
